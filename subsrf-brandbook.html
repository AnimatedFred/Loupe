Brand Story

What lives beneath

Every interface has two layers. The surface is what users see. The subsurface is what developers live in — selectors, computed styles, structure, hierarchy. Subsrf is the tool that bridges them.

Every UI has a surface and a subsurface.
Designers live on top. Developers live underneath.
AI needs both. Subsrf gives it both.

01 — PRECISE
Exact data, always

Subsrf deals in computed values — not raw CSS, not estimates. Pixels, not ems. Resolved colors, not variables. When you relay element data through Subsrf, it is exact. The brand reflects this: no softness, no approximation.

02 — DEEP
Goes further than the surface

Other tools show you the surface. Subsrf reads the layer beneath — the actual computed state of any element on any page. XPath, selectors, layout, the full style tree. That depth is the product and the brand.

03 — CONNECTED
The bridge between everything

Browser to AI. Browser to Figma. Browser to test suite. Subsrf doesn't care where it sends — it's the universal pipe for UI context. The neon green accent is the signal that data is moving.

04 — TRUSTED
Infrastructure, not a gadget

Developers and designers pipe their work through Subsrf. It has to feel like infrastructure. The dark palette, the monospaced wordmark, the sparse use of color — all of it signals that this is a serious tool built by people who ship.

Voice & Tone

How Subsrf speaks

Our users spot bad copy the way they spot a memory leak. Write with the precision of someone who ships production code and the taste of someone who uses Linear.

Terminal-brief

Say the thing. No warm-up. No outro. If you can cut a word without losing meaning, cut it.

"4 elements captured."
Not: "Great work! You've selected 4 elements and they're ready to use."

Technically fluent

Use correct terms. XPath, not "the element path thing". Computed styles, not "CSS stuff". But don't show off — accuracy isn't the same as density.

"Computed styles and XPath included."
Not: "We've included the computed cascaded style properties and XML path expression."

Flat affect, no hype

We don't celebrate. We confirm. The tool did its job — state that, move on. Save enthusiasm for the product, not the copy.

"Sent to MCP."
Not: "🎉 Your elements have been successfully relayed to your AI client!"

Dry, occasionally

One dry line in the right place is earned. Never more than one per screen. Never forced.

"No API key. We checked."
"Works with your AI. All of them."
